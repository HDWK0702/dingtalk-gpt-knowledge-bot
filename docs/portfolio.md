# 企业知识库问答机器人

一个面向企业内部资料的 RAG 问答项目：员工在钉钉提问，系统先按状态、部门和权限检索已发布资料，再由大语言模型生成带来源的回答。

## 项目亮点

- 钉钉 Stream 机器人：员工在熟悉的聊天入口提问。
- Markdown/Obsidian 知识源：支持章节化文档、版本和生效状态。
- 资料权限控制：草稿、归档、排除资料和无权限部门资料不会进入员工检索。
- Embedding + pgvector 兼容设计：按语义检索相关内容。
- 保守回答：找不到足够依据时拒答，不让模型凭空补充。
- 上下文记忆：分析新问题是否承接上一轮，再决定是否带入上下文。
- 失败切换、去重、日志和分阶段耗时记录：便于稳定性和性能排查。
- Docker 化运行：可从本地迁移到 ECS、RDS、Redis 和 OSS。

## 架构

```text
钉钉 Stream
    ↓
FastAPI / Python 服务
    ↓
问题分析、状态过滤、权限过滤
    ↓
Embedding → 向量检索 →（可选重排序）
    ↓
大语言模型生成答案，程序根据检索记录生成来源
    ↓
钉钉回复 + 问答/性能日志
```

## 如何查看效果

### 方式一：打开交互式演示

当前仓库未提供 `demo/index.html` 静态演示页。可在本地配置测试环境后，用自行编写的虚构资料展示问答；`cards/wide-answer.preview.html` 仅用于查看卡片排版草稿，不代表真实问答或钉钉客户端效果。

### 方式二：看演示资料

当前仓库未附带演示知识文件，请先建立独立的虚构资料目录。可展示三类场景：

1. 企业资料问题：返回相关说明和来源。
2. 草稿、归档或无权限资料不会被引用。
3. 无依据问题：明确拒答并建议联系管理员。

### 方式三：本地运行

1. 复制 `.env.example` 为 `.env`，填入你自己的钉钉、模型和 Embedding 配置。
2. 将 `OBSIDIAN_VAULT_PATH` 指向演示知识库或你自己的知识库。
3. 运行 `python index_knowledge.py` 建立向量索引，具体环境与 Docker 命令见 README。
4. 运行 `python main.py`，在测试群中提问。

公开仓库不要放真实 `.env`、真实 Obsidian 文件、问答日志、性能日志或 `rag_index.json`。

### 发布成公开网址

当前仓库没有 GitHub Pages 发布工作流或完整静态演示站点，推送不会自动发布可体验的机器人网址。真实机器人需配置钉钉应用和模型服务，并在本地或服务器运行。

## 建议录制的 60 秒演示

1. 在钉钉输入“第三类医疗器械办理需要哪些材料”，展示系统命中资料并给出来源。
2. 追问“那办理周期呢”，展示上下文承接。
3. 输入一个资料中没有的问题，展示保守拒答。
4. 打开脱敏后的性能日志，展示检索和模型阶段耗时。

截图或视频中请遮挡员工姓名、手机号、群名称、内部文件名、API 地址和任何密钥。

## 生产化方向

当前已支持 PostgreSQL + pgvector 运行时检索及 Docker 服务编排，仍保留 JSON 适配器。云端迁移可使用托管数据库、Redis、日志及密钥管理服务；生产安全和容量仍需按实际环境验证。自定义宽屏模板、钉盘文档跳转的真实客户端效果仍待验收。
